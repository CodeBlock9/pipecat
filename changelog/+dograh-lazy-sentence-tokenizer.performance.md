- NLTK is imported the first time a sentence is tokenized rather than when `pipecat.utils.string` is imported, and the `punkt_tab` data check moves with it. At import scope that check touched the filesystem and could reach the network before the caller had done anything, in every process that imported the module for its tag parsing alone. Together with the volume change, this takes nltk, pyloudnorm and scipy out of the import graph of every pipecat module the application loads.
