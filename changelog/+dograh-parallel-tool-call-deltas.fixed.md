- The OpenAI chat-completions streaming loop, which every OpenAI-compatible service runs, now runs every tool call of a turn. It read only the first tool call of each streamed delta and gated the whole batch on the last call's name, so a provider that sent two calls in one delta lost the second, one that interleaved their fragments ran none, and a stream without indices ran a phantom call with no name. Calls are now gathered by index, or by id when the provider sends no index; a call with no name or with unparseable arguments is skipped with a warning while the others run. A usage chunk that leaves a count out reports it as 0 instead of failing the turn. `SambaNovaLLMService` drops its own copy of the loop and runs this one.
