- `WakePhraseUserTurnStartStrategy(single_activation=True)` returns to IDLE when the user turn stops, so the next turn needs the wake phrase again. Until the keepalive timeout expired, every later turn passed ungated. The keepalive stays as the fallback for a turn that has not stopped, and activity now refreshes it in this mode too: it used to expire `timeout` after the wake phrase even while the user was still speaking, and the request's next transcription, arriving in IDLE, reset the aggregation and dropped what the user had said. In this mode `on_wake_phrase_timeout` fires only from that fallback.
