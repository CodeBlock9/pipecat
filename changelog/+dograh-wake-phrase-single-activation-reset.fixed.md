- `WakePhraseUserTurnStartStrategy(single_activation=True)` returns to IDLE when the user turn stops, so the next turn needs the wake phrase again. Until the keepalive timeout expired, every later turn passed ungated. The keepalive stays as the fallback for a turn that has not stopped within `timeout` of the wake phrase; in this mode `on_wake_phrase_timeout` fires only from that fallback.
