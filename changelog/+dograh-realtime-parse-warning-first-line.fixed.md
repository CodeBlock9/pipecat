- `GrokRealtimeLLMService` and `InworldRealtimeLLMService` log a server event they cannot parse as `OpenAIRealtimeLLMService` does, with a warning that names the event's type and the error's first line. The warning used to carry the whole error, and the parse error repeats the raw event after its first line, so a caller's transcript or base64 audio reached the log. All three realtime families now log `Failed to parse server event of type <type>: <first line>` and skip the event.
