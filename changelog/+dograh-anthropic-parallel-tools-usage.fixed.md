- `AnthropicLLMService` now runs every `tool_use` block of a message, in index order. It kept one accumulator that each new block replaced, so a turn that asked for two tools ran only the last; a block whose JSON does not parse is now skipped with a warning while the others run, where it used to fail the turn. Usage counters are read as the cumulative values Anthropic reports: each keeps the latest non-null value from `message_start` and `message_delta`, so a `message_delta` without `input_tokens` no longer fails the turn, and one that repeats the cumulative `input_tokens` no longer doubles the prompt tokens.
