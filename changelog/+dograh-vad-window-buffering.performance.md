- `VADAnalyzer` accumulates audio into whole model windows on the event loop and hands only whole windows to the model, instead of making an executor round trip for every chunk a transport delivers. At 8 kHz a 20 ms chunk is smaller than the 32 ms window, so more than a third of those round trips did nothing but append. Inference now runs on one pool shared by every analyzer in the process rather than a single-thread pool per analyzer: a Silero window takes well under a millisecond, so the pool follows simultaneous inference instead of concurrent calls, and `cleanup()` no longer has a thread of its own to release.
