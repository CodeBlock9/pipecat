- `VADAnalyzer` accumulates audio into whole model windows on the event loop and hands only whole windows to the model, instead of making an executor round trip for every chunk a transport delivers. At 8 kHz a 20 ms chunk is smaller than the 32 ms window, so more than a third of those round trips did nothing but append. Inference runs on one pool shared by every analyzer in the process rather than a single-thread pool per analyzer: a Silero window takes well under a millisecond, so the pool follows simultaneous inference instead of concurrent calls, and one analyzer per call no longer means one operating-system thread per call. `cleanup()` drops the analyzer's buffered audio and leaves the shared pool alone — shutting it down would stop voice detection for every other call in the process.
