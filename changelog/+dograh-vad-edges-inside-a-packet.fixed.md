- A speech start or stop that an audio packet completes reaches `VADController` even when the packet holds several model windows. `VADAnalyzer` promoted its state only after the packet's last window, so a start followed by a quiet window in the same packet, or a stop followed by a voiced one, was never reported. The analyzer now returns at the first start or stop and keeps the windows after it buffered, and the controller asks it again, with no new audio, until no start or stop is left.
