- `LLMAssistantAggregatorParams.interrupted_aggregation_callback`: an optional callback the assistant aggregator applies (after `correct_aggregation_callback`) to the aggregation of a turn that a live `InterruptionFrame` cut short, so the application can decide what the context records for a truncated utterance — for example the full intended text of a greeting. `EndFrame`/`CancelFrame` teardown does not engage it.
