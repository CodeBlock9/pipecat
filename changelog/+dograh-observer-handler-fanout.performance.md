- `WorkerObserver` no longer queues an event for an observer that has not overridden the handler it would be delivered to. `BaseObserver.on_process_frame` and `on_push_frame` are both `pass`, so an observer that implements only one of them was being woken for every event of the other kind: on a telephony call that was more than half of all observer queue traffic. Which handlers an observer overrides is recorded once, when its proxy is created, and an observer that overrides neither is sent nothing.
