- `FrameProcessor` no longer builds a trace string for every frame it pushes. The two `logger.trace` lines on the push path interpolated the frame itself, and `Frame.__str__` formats an audio frame's size, sample rate, channel count and presentation timestamp -- work done on every push of every chunk whatever the log level, and discarded at anything above TRACE. The other trace lines in the file interpolate only the processor's cached name and are unchanged.
