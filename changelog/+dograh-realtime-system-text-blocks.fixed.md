- The OpenAI Realtime, AWS Nova Sonic, Grok Realtime and Inworld Realtime adapters now keep every text block of a system message given as a list of content parts, joined with a space, as the other adapters already did. They read only the first block, so a system prompt split into blocks lost everything after it, and a system message whose content was an empty list raised `IndexError` while the context was converted. All of them, and `_extract_initial_system`, now read the text through one helper, `BaseLLMAdapter._system_text`, which gives `None` for content that is neither a string nor a list.
