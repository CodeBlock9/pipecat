- `LLMAssistantAggregator` logs `LLM generation produced no text` when a generation ends having produced neither text nor a function call. A model that answers with nothing pushes no error frame and leaves a run that reads as complete, so this line is the only signal such a turn has. `EMPTY_COMPLETION_LOG` is exported as a module constant for log-based alarms. A tool-only turn legitimately produces no text and is not reported.
