- `MCPClient` now lists every page of an MCP server's tool catalog, following `nextCursor` until the server returns none, for `tools()` and the deprecated `get_tools_schema()` and `register_tools()` alike. It read only the first page, so tools on later pages were never offered to the LLM, and a `tools_filter` naming one of them matched nothing. A cursor the server has already returned ends the listing, and a tool name listed more than once keeps its first listing, so a server that ignores the cursor can neither loop nor put the same tool name in front of the LLM twice. The listing has no bound of its own; a caller that needs one wraps it in its own timeout.
